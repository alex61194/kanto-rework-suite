# Asset provenance

The animation graphics, `PkmnAnimations.rxdata` source data and sound effects were supplied by the user from the archive `Gen 9 Move Animation Project.zip`. Redistribution/licensing rights for those third-party assets were not independently verified in this build.

The runtime bridge is newly authored for Kanto Rework and targets Gen1Recomp 0.1.80 / Mod API 2.
