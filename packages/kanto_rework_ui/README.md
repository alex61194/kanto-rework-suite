# Kanto Rework UI 🎨

The visual and interaction layer of the Kanto Rework Suite for Gen1Recomp.

## Features

- 📊 **Resumen Moderno de Pokémon**: Visualización de estadísticas, DVs (0-15), Stat Exp con barras de progreso y descripción de movimientos en español.
- 🎒 **Mochila en 8 Bolsillos**: Separación por Medicinas, Poké Balls, Combate, MTs/MOs, Clave, etc., con descripciones completas.
- ⚔️ **HUD de Combate en Tiempo Real**: Visualización de modificadores de estadísticas (`+2 ATK`, `-1 VEL`) y cálculo de efectividad elemental de movimientos.
