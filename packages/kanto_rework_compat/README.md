# Kanto Rework Compatibility 🔗

Third-party mod settings, accessibility profiles, and provider resolution.

## Features

- ⚙️ **Gestor de Ajustes de Mods**: Configuración de mods de terceros desde un menú dedicado.
- 👁️ **Perfiles de Accesibilidad**: Modos de visión para Protanopia, Deuteranopia y Tritanopia.
- 🎨 **Selección de Proveedores Visuales**: Intercambio de sprites de combate clásicos, Kanto Ascendant o Voxel 3D.
