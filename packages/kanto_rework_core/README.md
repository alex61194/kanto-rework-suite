# Kanto Rework Core 🧱

The foundational module for the Kanto Rework Suite on Gen1Recomp.

## Features

- 🌐 **Internacionalización (i18n)**: Soporte completo para Español e Inglés con cambio dinámico en caliente.
- 📐 **Diseño Adaptable (Multi-Ratio)**: Soporte nativo para 16:9, 16:10 (Steam Deck), 21:9 (Ultrawide), 4:3 (Retro) y 9:16 (Portrait).
- 🎨 **Temas Visuales**: Field Journal (clásico cálido), Graphite (oscuro moderno), Purple Night y Retro DMG.
- 🖱️ **Puntero y Táctil Semántico**: Navegación fluida por ratón y pantalla táctil para menús, combates, elecciones y mochila.
- 💾 **Guardado Seguro Atómico**: Prevención de corrupción mediante `.sav.tmp` y recuperación automática desde `.sav.bak`.
- 🪟 **Overlay de Acompañante**: Widget móvil de información de entrenador (F8 mostrar/ocultar, F9 modo edición).
